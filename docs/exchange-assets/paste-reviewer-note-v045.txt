This is an update to the approved v0.37.0. The test steps are the same as for that review.

OpenLayer is a client for ComfyUI, a free local AI image server, installed and started separately. It bundles neither ComfyUI nor any model.

Install video (CPU test, slow): https://youtu.be/O54rCD6boIs

To test one workflow:
1. ComfyUI Desktop, CPU build: https://www.comfy.org/download
2. Put https://huggingface.co/Comfy-Org/stable-diffusion-v1-5-archive/resolve/main/v1-5-pruned-emaonly-fp16.safetensors in %LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared\models\checkpoints
3. Plugins > OpenLayer > Text to Image > txt2img-basic > 512 x 512 > Generate > Import to Layers.

New in this version: support for Photoshop 2027 (28.0). I tested it on Windows 11 with Photoshop 2025 and 2027. With an NVIDIA GPU every feature can be tested, much faster.

No telemetry, no accounts. The network reaches only the ComfyUI address and model hosts the user confirms.
