# OpenLayer v0.36.0 — Edit Image

Written 2026-09-23 after v0.35.0 shipped. Proposed by Mehran; built as **option B** (his choice):
Edit Image is an *edit mode* of the Image to Image screen with its own Home card, not a separate
tool.

## Why

Two techniques share the Image to Image screen today:

| | Image to Image (`img2img-*`) | Edit (`edit-flux2-klein`, `edit-qwen-image-21`) |
|---|---|---|
| How it works | The layer is the starting latent, sampled at denoise < 1 | The layer is *conditioning*; sampling starts empty at denoise 1 |
| What you write | A description of the whole picture | An instruction: what to change |
| The Denoise slider | The main control | **Ignored** — yet still shown |
| Where it is going | Stable | Every new Qwen-Image 2.1 capability |

Both edit presets declare `hiddenControls: ["denoise"]`, but no screen reads `hiddenControls`, so an
artist moving the slider on an edit preset changes nothing and is not told why.

## Option B, and why over a separate tool

Option A (a separate tool: own screen, source, result, history type, Preview slot, busy rules,
Prompt Wallet entry, bridge tool) is about 16 files plus a history migration, and the largest markup
change the panel has had. Option B gives the artist the same experience at a fraction of the risk
and can still grow into A later:

- A new **Edit Image** card on Home opens the Image to Image screen in edit mode.
- **Edit mode:** title "Edit Image"; the Workflow list shows only the edit presets; Denoise, LoRA and
  Experimental Checkpoints are hidden; the prompt asks *"What should change?"*; a one-line hint
  under the model picker follows the preset (the `screenHint` pattern from v0.35).
- **Image to Image mode:** the Workflow list shows only the denoise presets, so its slider always
  means something.
- Capture, result, import, history and the Preview panel are shared and unchanged. The accepted cost:
  a layer captured in one mode is still there in the other, and both use one result slot.

Nothing needs migrating. Preset ids, modes and graphs do not change; which mode a preset belongs to
is derived from whether its capability offers a denoise control. A history entry for an edit preset
reopens in edit mode.

## Tasks (one commit each; a Photoshop gate after every task that touches the panel)

1. **Edit mode** — the card, the mode switch, filtering, hidden controls, placeholder, title and
   hint. Markup is one card and one hint line; the rest is behaviour. Gate with screenshots of both
   modes.
2. **Agent Bridge** — an `edit_image` tool that opens edit mode; `image_to_image` keeps accepting
   edit presets for one release.
3. **Docs** — README tool table, landing page, known limitations, CHANGELOG.

Then the capabilities the mode exists to grow, each behind its own spike and gate:

4. **Edit a selection** (Qwen-Image 2.1). Cut from v0.35 because a smooth sky showed the edge — the
   model repaints untouched areas 6–12 levels darker. Whole-crop `ColorTransfer` made the busy case
   worse (+8.7 levels). The fix to spike: match colour using **only the untouched ring** outside the
   selection. Any whole-image statistic is diluted by (1 − f), where f is the selection's share of the
   crop, and the panel already has the mask bytes when it encodes the upload, so it can pass
   strength ≈ 1 / (1 − f). Ship only if the sky case shows no edge at 100% and after a Curves boost.

   **Spike result (2026-09-23): passes.** Core nodes only: `ImageCompositeMasked` builds a
   "ring-only" frame (original inside the selection, edit outside), `ImageBatch` puts it before the
   edit, `ColorTransfer` (reinhard_lab, `source_stats: target_frame` 0, strength 1/(1 − f)) computes
   the transform from that frame and applies it to both, `ImageFromBatch` takes the corrected edit,
   and a 31 px feathered mask composites it. Step across the selection edge, edited content
   excluded:

   | Case | Hard edge | Feathered | **Ring match + feather** | v0.35 whole-crop match |
   |---|---:|---:|---:|---:|
   | Smooth sky (balloon), f = 0.22 | −1.96 (sharp) | −1.05 | **−0.12** | — |
   | Busy street (cart → bicycle), f = 0.38 | −0.54 | — | **+1.36** | +3.75 |

   At 1:1 with a 6× contrast boost the sky edge is invisible with the ring match, faint with
   feathering alone, and obvious with a hard edge. The busy case moves 1.4 levels, below visible on
   textured content. An earlier reading that the model's drift is "non-uniform across the frame"
   was a measuring artefact: the edited balloon and the trees sat inside the measured bands.
5. **Reference layers in an edit** (Qwen-Image 2.1): "put the jacket from layer 2 on her". Reuses
   v0.35's `encoder-image-slots` wiring with image_1 as the layer being edited.
6. **2K edits** (Qwen-Image 2.1): a Detail choice of 1 MP or 4 MP, measured against the upstream
   schedule fix (ComfyUI #16447) first.
