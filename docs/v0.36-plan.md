# OpenLayer v0.36.0 — Edit Image gets its own tool

Written 2026-09-23, before v0.35.0 shipped. Proposed by Mehran, agreed for v0.36 rather than v0.35
so the v0.35 smoke test is not restarted by a new tool screen.

## Why

Two different techniques share the Image to Image screen today:

| | Image to Image (`img2img-*`) | Edit (`edit-flux2-klein`, `edit-qwen-image-21`) |
|---|---|---|
| How it works | The layer is the starting latent, sampled at denoise < 1 | The layer is *conditioning*; sampling starts empty at denoise 1 |
| What you write | A description of the whole picture | An instruction: what to change |
| The Denoise slider | The main control | **Ignored** — yet still shown |
| Where it is going | Stable | Every new Qwen-Image 2.1 capability |

The slider is the concrete bug. Both edit presets declare `hiddenControls: ["denoise"]`, but no screen
reads `hiddenControls` (found in the v0.35 audit), so an artist moving the slider on an edit preset
changes nothing and is not told why. And the features waiting on Qwen-Image 2.1 are all edit
features: cut-outs that stay cut-outs (shipped in v0.35), editing only a selection (cut from v0.35 —
see below), extra reference layers inside an edit, and a 2K option.

## The tool

**Edit Image** — its own card on Home, beside Image to Image.

- Capture the active layer or canvas, exactly as Image to Image does (same capture code).
- One prompt box, placeholder *"What should change? e.g. change the sign to read OPEN"*.
- Workflow: FLUX.2 Klein (edit) — the default, Apache-2.0 — or Qwen-Image 2.1 (edit, research licence).
- Steps, CFG and seed. **No Denoise.** No width/height: the result is the captured layer's size.
- A one-line hint under the model picker that follows the preset (the `screenHint` pattern v0.35
  introduced for Multi-Reference).
- Result imports as a new layer aligned over the source; a cut-out source comes back as a cut-out
  with Qwen-Image 2.1.

Image to Image keeps its three denoise presets (standard, Klein, Z-Image, Krea-2), so its slider
always means something.

## Not breaking anything

- **Preset ids stay the same.** `edit-flux2-klein` and `edit-qwen-image-21` move from mode `img2img`
  to a new mode `edit`; their graphs, node ids and model stacks do not change.
- **History:** entries recorded as Image to Image with an edit preset reopen on the Edit screen.
- **Saved preferences** naming an edit preset for Image to Image fall back to that screen's default.
- **Agent Bridge:** new `edit_image` tool. For one release `image_to_image` still accepts the two
  edit presets and routes them to the new screen, then that path is removed.

## Tasks (one commit each, a Photoshop gate after every task that touches the panel)

1. **Screen only** — card, screen markup and capture wired, no presets moved yet. Markup change, so it
   goes to the gate alone with a screenshot.
2. **Move the two edit presets** to mode `edit`; Image to Image's list shrinks; history and
   preference fallbacks; frozen inventories (`presetRegistry`, `toolDescriptors`, `previewHub`,
   `importBridge`, `promptWallet`, `textareaMaxLength`, `homeToolSections`, protocol parity).
3. **Agent Bridge** `edit_image`, plus the one-release alias on `image_to_image`.
4. **Enhance Prompt and the Prompt Wallet** on the new prompt box (they are per-field tables).
5. **Docs** — README tool table and gallery, landing page, known limitations, CHANGELOG.

Then the capabilities the screen exists to grow, each behind its own spike and gate:

6. **Edit a selection** (Qwen-Image 2.1). Cut from v0.35 because a smooth sky showed the edge — the
   model repaints untouched areas 6–12 levels darker. Whole-crop `ColorTransfer` made the busy case
   worse (+8.7 levels). The fix to spike: match colour using **only the untouched ring** outside the
   selection. Any whole-image statistic is diluted by (1 − f), where f is the selection's share of the
   crop, and the panel already has the mask bytes when it encodes the upload, so it can pass
   strength ≈ 1 / (1 − f). Ship only if the sky case shows no edge at 100% and after a Curves boost.
7. **Reference layers in an edit** (Qwen-Image 2.1): "put the jacket from layer 2 on her". Reuses
   v0.35's `encoder-image-slots` wiring with image_1 as the layer being edited.
8. **2K edits** (Qwen-Image 2.1): a Detail choice of 1 MP or 4 MP. 4 MP is about four times slower;
   worth measuring against the upstream schedule fix (ComfyUI #16447) first.

## Cost, measured from v0.35's audit

A new tool screen touches about 16 files (the audit's Checklist B in `docs/v0.35-plan.md` §2); moving
a preset between modes touches the registry, `types.ts` and the frozen per-mode lists. No new models,
no new custom nodes, no new downloads.
